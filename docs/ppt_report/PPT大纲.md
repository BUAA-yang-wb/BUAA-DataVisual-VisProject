# 《职数洞见》期末汇报 PPT 大纲

> 用途：为后续正式制作 PPT 提供结构、页面内容和截图占位。本文只写大纲，不生成逐字讲稿。

## 1. 汇报定位

- 项目主题：基于 JobWanted 招聘数据的招聘市场可视分析系统。
- 汇报目标：说明小组如何完成数据清洗、分析设计、可视化系统实现，并从数据中提炼招聘市场洞见。
- 时间约束：课堂展示 6 分钟以内，建议控制在 10-12 页，最多不超过课程要求的 15 页。
- 推荐主线：应用场景 -> 数据处理 -> 系统设计 -> 四个核心视图 -> 交互与洞见 -> 总结。
- 复核依据：`docs/VISProject.md` 的评分点和汇报要求、`docs/项目分工.md` 的 A/B/C/D 交付边界、`docs/成员D_分析设计包.md` 的分析设计、`docs/成员B_数据处理包.md` 的数据口径、`docs/成员C_系统实现包.md` 的系统实现说明，以及 `data/processed/insights.json` 的洞见证据。
- 制作原则：每一页都服务课程得分点，避免只展示界面截图；截图旁边必须说明“它回答了什么分析问题”或“体现了什么系统能力”。
- 成稿约束：最终 PPT 正文必须是面向课堂听众的汇报语言，不得出现“截图占位”“建议截取”“讲解重点”“演示建议”“本页保留”“便于截图/指示/制作”等制作过程说明。此类内容只允许留在本大纲、截图说明或演讲备注中。
- 展示重点：最终成稿需要显性覆盖课程评价方式中的五个方面：场景的新颖性和实用性、数据处理的卓越性和准确性、可视化设计、工具的可用性、汇报展示。页面上不直接写“评分点回扣”，而是转化为问题引入、处理证据、设计逻辑、工具链和项目完成度。
- 版式约束：正式 PPT 应优先保证课堂投影可读性，正文尽量不低于 15pt，字幕/说明尽量不低于 17pt；若文本溢出，应删减或重排，不依赖压缩字体。

## 4. PPT 页面大纲

### 第 1 页：封面

- 标题：《职数洞见：招聘市场可视分析系统》
- 副标题：基于 JobWanted 数据的多维招聘活动、薪酬模式与地域画像分析
- 信息：课程名称、小组成员、汇报日期
- 视觉建议：简洁标题页，可使用系统主色或招聘/数据分析相关背景纹理。
- 图片占位：无必须截图；可放一张弱化处理的系统首页截图作为背景。

### 第 2 页：问题引入与应用场景

- 场景：企业希望理解招聘市场动态，优化人才招聘策略；求职者希望比较城市、行业、职位和薪资机会。
- 痛点：
  - 招聘信息规模大，单条浏览难以形成整体判断。
  - 薪酬、经验、学历、地域、行业之间存在交叉影响。
  - 匿名编码数据缺少语义标签，更需要通过结构化指标发现相对差异。
- 本项目目标：构建一个可交互的可视分析系统，支持从市场概览到细分画像的逐层探索。
- 对应题目任务：
  - 多维度量化职位差异。
  - 展示职位画像。
  - 建模和呈现薪酬模式差异。
  - 挖掘地域招聘画像和相似地域。
- 图片占位：可放“分析问题四象限”示意图，后续可用 PPT 自绘，不一定需要系统截图。

### 第 3 页：数据来源与字段说明

- 数据来源：JobWanted 招聘通知数据。
- 题目给定的原始规模：
  - 原始记录数：430,664 条
  - 覆盖职位代码：169,540 种
  - 覆盖企业：267,296 家
  - 覆盖行业类别：158 类
  - 覆盖行政区划：371 个
- 当前清洗产物规模：
  - 清洗后记录数：421,160 条
  - 清洗后职位代码数：165,235
  - 清洗后企业代码数：263,268
  - 清洗后城市代码数：371
  - 清洗后行业类别数：158
- 核心字段：`job_title`、`city`、`salary`、`experience`、`education`、`company`、`company_type`。
- 说明：字段均为匿名代码，本项目不强行解释具体城市/行业名称，而是分析编码之间的相对结构。
- 图片占位：放“字段说明表”或原始数据样例截图；可从 `docs/JobWanted_description.md` 或表格软件截取。

### 第 4 页：数据清洗与指标构造

- 清洗目标：将原始招聘记录转为可计算、可聚合、可接入前端的数据包。
- 清洗规则：
  - 去除无效薪资记录。
  - 去除完全重复记录。
  - 保留合法城市代码。
  - 解析 `5-10K`、`5-10K·13薪` 等薪资文本。
- 关键结果：
  - 清洗后记录数：421,160 条
  - 剔除记录数：9,504 条
  - 无效薪资剔除：9,451 条
  - 完全重复剔除：53 条
  - 数据保留率：97.79%
  - 平均月薪：9.58K
  - 中位月薪：7.50K
- 派生指标：最低月薪、最高月薪、平均月薪、估算年薪、薪资分箱、薪资等级。
- 交付产物：`cleaned_jobs.csv`、`overview.json`、`quality_report.json`、`insights.json`、`aggregates/*.json`、`views/*.json`。
- 图片占位：放“数据处理流程图”；可用 PPT 自绘 `原始 CSV -> 清洗 -> 薪资解析 -> 聚合统计 -> 页面 JSON`。

### 第 5 页：整体系统架构

- 架构主线：
  - 成员 D：提出分析问题、页面设计和数据需求。
  - 成员 B：通过 `scripts/process_member_b.py` 生成清洗数据与聚合 JSON。
  - 成员 C：使用 `vision/` 静态页面和 ECharts 实现可视化系统。
  - 成员 A：整合材料，制作 PPT 和汇报。
- 数据流：
  - `data/JobWanted.csv`
  - `data/processed/cleaned_jobs.csv`
  - `data/processed/aggregates/*.json`
  - `data/processed/views/*.json`
  - `vision/index.html`
- 技术点：Python 标准库数据处理、JSON 数据交换、ECharts 图表、静态本地服务器。
- 注意口径：虽然早期分工文档中提到 Vue/Vite，当前实际可运行系统为 `vision/` 下的静态 HTML + CSS + JavaScript + 本地 ECharts，更适合课堂离线演示。
- 图片占位：放“系统架构图”；可自绘，也可截取项目目录结构作为辅助图。

### 第 6 页：分析设计：四个核心视图

- 四个分析问题与页面对应：
  - 市场总览：招聘规模和整体结构如何？
  - 薪酬分析：薪资差异与哪些因素相关？
  - 职位画像：高频职位的城市、行业、薪资和要求有什么特征？
  - 地域画像：哪些城市招聘特征相似？
- 设计原则：
  - 总览先行，帮助快速建立全局判断。
  - 多维拆解，分别观察城市、行业、职位、经验、学历。
  - 交互联动，支持从一个发现继续追问。
- 与成员 D 产物对齐：四个页面分别继承 `docs/成员D_分析设计包.md` 中的市场总览、薪酬模式、职位画像、地域画像设计。
- 与成员 B/C 产物对齐：四个页面直接读取 `data/processed/views/` 下的页面级 JSON，降低前端二次加工成本。
- 图片占位：放“四页面导航截图”；打开系统首页后截取顶部导航和四个标签页名称。

### 第 7 页：页面展示一：市场总览

- 页面作用：快速理解招聘市场规模、城市/行业分布、薪酬和要求结构。
- 主要图表：
  - KPI 卡片：岗位总数、覆盖城市数、覆盖行业数、平均月薪、中位月薪、数据保留率。
  - Top 城市柱状图：展示招聘活跃城市。
  - Top 行业柱状图：展示招聘活跃行业。
  - 薪酬分布直方图。
  - 经验/学历占比饼图。
- 可讲洞见：
  - 城市 `F047` 招聘记录数最多，24,896 条，占清洗后数据的 5.9%，平均月薪 14.66K。
- 得分点落位：这里重点体现 Usage scenario 的全局市场理解，以及 Interesting insight from data 的城市活跃度发现。
- 图片占位：放“市场总览页面截图”。建议截取系统 `市场总览` 页面全屏，重点包含 KPI、Top 城市、Top 行业和薪酬分布。

### 第 8 页：页面展示二：薪酬模式分析

- 页面作用：比较薪酬在城市、行业、经验、学历维度上的差异。
- 主要图表：
  - 城市薪资箱线图。
  - 行业薪资箱线图。
  - 城市 x 行业薪资热力图。
  - 城市/行业薪酬散点图。
  - 经验/学历薪资分组柱状图。
- 交互亮点：
  - 最低岗位数阈值滑条可以过滤样本过少的城市或行业。
  - 指标和筛选状态会影响薪酬图表的显示范围。
- 可讲洞见：
  - 行业 `type_PkWZvJ` 在样本数不少于 100 的行业中平均月薪最高，平均月薪 17.89K，中位月薪 12.50K。
  - 经验代码 `EaZ` 的平均月薪最高，达到 24.86K。
- 得分点落位：这里重点体现薪酬待遇模式建模、薪资差异识别，以及阈值过滤交互。
- 图片占位：放“薪酬分析页面截图”。建议截取 `薪酬分析` 页面，优先包含箱线图、热力图和阈值滑条。

### 第 9 页：页面展示三：职位画像

- 页面作用：从高频职位切入，观察职位规模、薪资水平、经验/学历要求和偏好城市/行业。
- 主要图表：
  - 热门职位 Top 柱状图。
  - 职位薪酬折线，可切换平均月薪/中位月薪。
  - 职位要求堆叠柱。
  - 职位画像卡片。
- 交互亮点：
  - 点击职位柱状图后，系统联动该职位的典型城市和行业。
  - 卡片展示该职位的热门城市、热门行业和薪资区间。
- 可讲洞见：
  - 职位代码 `bfbc45b05c5a4425210cd2cb3d84ae09GC` 出现次数最多，共 3,328 条，平均月薪 7.79K。
  - 该职位的热门城市包括 `S542`、`N806`、`V932`、`R892`、`V449`。
- 得分点落位：这里重点回应题目中的职位画像展示和职位差异分析。
- 图片占位：放“职位画像页面截图”。建议截取 `职位画像` 页面，重点包含 Top 职位图和画像卡片。

### 第 10 页：页面展示四：地域画像

- 页面作用：从城市角度观察招聘活跃度、薪资水平、行业多样性和相似城市。
- 主要图表：
  - 城市雷达图。
  - 相似城市聚类散点。
  - 城市薪资与岗位数对比图。
  - 相似城市 Top 列表。
- 交互亮点：
  - 城市下拉选择联动雷达图与相似城市列表。
  - 聚类数可选，帮助观察城市群结构。
  - 选中城市会在散点图中高亮。
- 可讲洞见：
  - 城市 `H610` 在样本数不少于 100 的城市中平均月薪最高，平均月薪 27.56K，中位月薪 22.50K。
- 得分点落位：这里重点回应地域招聘活动画像和相似招聘特征地域识别。当前实现以雷达图、聚类散点、城市薪资与岗位数对比替代传统地图展示，讲述时应强调“地域特征向量”和“相似城市探索”。
- 图片占位：放“地域画像页面截图”。建议截取 `地域画像` 页面，重点包含城市雷达图、聚类散点和相似城市列表。

### 第 11 页：交互设计与演示路径

- 核心交互：
  - 顶部标签页切换四类分析视图。
  - 城市、行业、职位点击后更新联动筛选状态。
  - 薪酬页面支持最低岗位数阈值过滤。
  - 地域页面支持城市选择和聚类数切换。
  - 一键清除联动，方便课堂演示回到默认状态。
- 建议演示路径：
  1. 在市场总览页展示 KPI 和 Top 城市。
  2. 点击 `F047` 或其他头部城市，展示联动筛选状态。
  3. 切到薪酬分析页，调整最低岗位数阈值。
  4. 切到职位画像页，点击最高频职位。
  5. 切到地域画像页，选择城市并观察雷达图和相似城市。
- 得分点落位：这页主要证明工具可用性和 Interaction，不必讲太多数据结论，重点展示“系统能用、能探索、能联动”。
- 图片占位：放“交互联动截图拼图”。建议截取三张小图：顶部联动筛选状态、薪酬阈值滑条、地域画像城市下拉/聚类选择。

### 第 12 页：总结、价值与不足

- 项目价值：
  - 将 43 万余条招聘记录转化为可探索的可视分析系统。
  - 从城市、行业、职位、经验、学历等多个维度解释招聘市场结构。
  - 通过页面级 JSON 让数据处理和前端实现解耦，便于复现和展示。
- 项目完成度：
  - 数据源处理和数据挖掘：完成薪资解析、清洗、聚合与相似度分析。
  - 应用场景：服务企业招聘决策和求职市场理解。
  - 可视化设计：四视图覆盖总览、薪酬、职位、地域。
  - 交互：筛选、切换、点击联动、相似城市探索。
  - 数据洞见：提供带证据的城市、行业、职位和经验薪资发现。
- 局限与展望：
  - 匿名编码限制了真实地名、行业名和职位名解释。
  - 薪资使用区间中点估算，后续可加入更稳健的异常值处理。
  - 后续可加入更多语义映射、搜索和导出功能。
- 图片占位：可放“四个页面截图缩略拼图”作为收束画面，或放系统首页截图加关键词总结。
