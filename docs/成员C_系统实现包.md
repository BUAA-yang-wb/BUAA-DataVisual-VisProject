# 《职数洞见》成员C系统实现包

本文档用于交付给成员A进行汇报整理，并供成员B核对系统与数据口径的一致性。内容包含页面实现概览、交互说明、运行方式与已支持的数据文件。

## 1. 成员C任务目标

成员C负责将成员D的分析设计与成员B的聚合数据落地为可运行的可视化系统，保证课堂演示可用、交互清晰、数据口径一致。核心目标包括：

1. 搭建四个页面的前端展示框架。
2. 接入 `data/processed/views/` 的页面级 JSON 数据。
3. 实现点击联动、筛选、指标切换与交互提示。
4. 处理可视化显示异常（溢出、遮挡、数值格式）。

## 2. 系统入口与运行方式

系统入口：

- `vision/index.html`

本地启动方式：

```bash
node vision/serve.js
```

浏览器访问：

```
http://localhost:8080/
```

说明：页面数据通过 `../data/processed/views/` 加载，使用本地静态服务器以避免 `file://` 跨域限制。

## 3. 页面结构与展示内容

### 页面A：市场总览

展示内容：

- KPI：岗位总数、覆盖城市数、覆盖行业数、平均月薪、中位月薪、数据保留率。
- 城市指标 Top：支持指标切换（岗位数/平均月薪/中位月薪）。
- 行业指标 Top：支持指标切换（岗位数/平均月薪/中位月薪）。
- 薪酬分布：薪酬分箱直方图。
- 经验/学历占比：双饼图展示占比结构。

数据来源：

- `views/overview_page.json`

交互与说明：

- 城市/行业 Top 支持点击高亮并联动其他页面筛选。
- 指标切换用于快速对比岗位规模与薪酬水平。

### 页面B：薪酬模式分析

展示内容：

- 城市薪资箱线图（Top 20）。
- 行业薪资箱线图（Top 20）。
- 城市 x 行业热力图（平均月薪）。
- 城市/行业薪酬散点图（气泡大小=岗位数）。
- 经验/学历与薪酬分组柱状图（平均值 vs 中位数）。

数据来源：

- `views/salary_patterns_page.json`

交互与说明：

- 最低岗位数阈值滑条 + 数字输入：同步过滤箱线图、热力图与散点图。
- 与页面A、C联动的城市/行业筛选会影响相关图表的数据范围。

### 页面C：职位画像

展示内容：

- 热门职位 Top（柱状图）+ 薪酬折线（可切换平均月薪/中位月薪）。
- 职位要求堆叠柱（经验分布）。
- 职位画像卡片（Top 6），展示热门城市、热门行业与薪资区间。

数据来源：

- `views/job_profile_page.json`

交互与说明：

- 点击职位柱状图联动城市/行业筛选。
- 卡片标题过长自动省略，悬停显示完整名称。

### 页面D：地域画像

展示内容：

- 城市雷达：活跃度、薪资水平、行业多样性、经验门槛。
- 相似城市聚类散点：基于城市特征向量降维。
- 城市薪资与岗位数对比图。
- 相似城市 Top 列表。

数据来源：

- `views/region_portrait_page.json`

交互与说明：

- 城市下拉选择联动雷达图与相似城市列表。
- 聚类数可选（默认 5 或 6），影响散点配色。
- 选中城市在散点图中高亮，并叠加白边橙色中心点。

## 4. 跨页面联动与筛选

全局联动状态：

- 联动筛选状态显示在页面顶部，可一键清除。

联动规则：

- 点击页面A的城市/行业 Top 条目：更新联动筛选（不自动跳页）。
- 点击页面C的职位 Top：更新职位、城市、行业联动筛选。
- 页面D城市选择：同步联动筛选并更新雷达与相似城市列表。

## 5. 交付文件清单

- `vision/index.html`：页面结构与控件。
- `vision/styles.css`：页面样式与布局。
- `vision/app.js`：数据加载、图表渲染与交互逻辑。
- `vision/serve.js`：本地静态服务器脚本。
- `vision/vendor/echarts.min.js`：本地 ECharts 资源。

## 6. 注意事项

1. 系统默认读取 `data/processed/views/` 下的四个页面级 JSON 文件。
2. 如需对聚合逻辑或阈值口径调整，应回到成员B的数据处理脚本修改再重跑。
3. 若课堂演示环境无法访问 CDN，当前已改为本地 ECharts 资源。

## 7. 交付说明

- 成员A可直接使用本系统截图、交互说明和运行方式撰写汇报材料。
- 如需添加额外图表或洞见展示，可从 `data/processed/aggregates/` 读取补充聚合数据。
